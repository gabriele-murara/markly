#Titolo senza spazio#

##Sottotitolo vecchio stile

Paragrafo con _underscore_ e __doppio underscore__.
* elenco subito dopo il paragrafo
* secondo elemento

1) elenco ordinato con parentesi
2) secondo

Riga con tag HTML inline: <b>grassetto</b>, <i>corsivo</i>, <u>sottolineato</u>, <tt>tt</tt>.

<center>Testo centrato (HTML 4)</center>

<font color="red">Testo rosso con &lt;font&gt;</font>

<table border="1" cellpadding="4">
<tr><td>Tabella</td><td>HTML</td></tr>
<tr><td align="right">vecchio</td><td>stile</td></tr>
</table>

Codice indentato con tab:

	int main(void) { return 0; }

Link di riferimento con titolo tra parentesi:

[esempio][1]

  [1]: http://example.com/  (Titolo)

Sintassi sconosciuta {: .classe } e [[WikiLink]] restano visibili come testo.
